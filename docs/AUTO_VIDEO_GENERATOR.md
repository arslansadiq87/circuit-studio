# Automatic video generator

Click **Auto Video** beside Present and Export. The default is a silent 1920×1080, 30 FPS H.264 MP4: opening, saved-order wiring explanation, completed circuit, and clean final hold. No recording permission, backend, AI service, or external encoder is needed. The adjacent **Video settings** dropdown is optional.

The generator resolves current component IDs and physical pin IDs. The default connection card is a lightweight, screen-space Futuristic 3D HUD with a layered glass/metal surface, subtle shadow and restrained teal edge. **Classic Technical** keeps the flat card, **Minimal** shows only the endpoints, and **No Labels** suppresses captions. HUD text and geometry are rasterized by the shared deterministic compositor used by preview and export. Its single header status dot is separate from the heading; source/destination spheres and the reveal-tip marker remain 3D scene objects and follow the export camera. Older saved settings that predate the style option open in Classic Technical; fresh Default Tutorial settings use the Futuristic HUD.

The final overview label can show the saved project name, a connection summary, or no closing label. Connection captions stay continuous through their paired camera move, reveal and hold, then fade at the end of that connection. The HUD corner is selected against projected component bounds, route points and pin anchors, and held stable for each shot. All positions use the renderer's 1920×1080 design space and scale to 1440p/4K output.

The previous caption dot overlapped `CONNECTION` because its fixed canvas center was drawn at nearly the same coordinates as the heading. It is now placed in a measured header slot before the text, with a documented 8-pixel diameter; world-space pin/wire markers remain separately projected and visibility-controlled. Hidden components/wires and broken references are excluded. Checked-net mode intersects checked IDs with the saved connection order. Nothing is inferred from signal names; duplicate GND labels retain component and physical pin IDs. No circuit positions, routes, colors, pin maps, undo entries or editor cameras are changed by preview/export.

Settings include Automatic Tutorial, All Connections, One by One, Selected Connections and Final Circuit Orbit; 1080p/1440p/4K; 24/30/60 FPS; MP4, WebM and numbered PNG ZIP; camera preference; reveal and hold durations; compact/detailed text; four card styles; three final-label policies; customizable solid/gradient backgrounds; optional floor, grid and shadows; completed wires; unrelated-wire fading; optional reveal-tip guide. The guide explains a connection and is not current simulation. Transparent output requires RGBA PNG frames. See [background settings, color handling and format limits](VIDEO_BACKGROUNDS.md).

Version 1 settings, overrides and the last chosen configuration are reusable local presets (`c3d-video-preset-v1`). Built-in presets are Default Tutorial, Fast Wiring Demonstration, Detailed Technical Explanation and Final Circuit Showcase. These are local browser settings, separate from electrical project serialization.

**Preview sequence** renders the same pipeline. Seek with the time slider or shot list. To override a shot, position the editor camera, select the desired shot, then choose **Use editor camera for shot** and rebuild the preview. Clear overrides restores automatic planning. Invalid or orphaned overrides produce warnings. **Save generated camera scenes** appends views to the Camera scenes tab; **Save view** also saves manual views. Local scenes are keyed by project name and never replaced by automatic generation. They are not currently embedded in portable project packages.

During export, the status shows preparation, current/total frame count, percentage, finalization and validation. Cancel stops at a safe pipeline boundary and restores editing detail. Save directly to file is optional and requires the browser file picker; the normal click downloads a finalized, decoded video. Codec failure names the limitation and points to supported alternatives, without changing formats silently.
