# Arduino Uno R3 asset preparation

Run `npm run optimize:arduino-uno` after placing the source archive at `Custom Components/arduino-uno/`. The script reads `source/Arduino UNO sketchfab.glb` and writes `public/models/arduino-uno-r3.glb` plus a reproducible JSON measurement report. It never modifies the source. The source GLB stays in metres; `modelScale: 1000` converts its centered clone to Circuit Studio millimetres at runtime.

The pipeline welds and simplifies the imported meshes with a 0.0005 relative error cap, merges compatible same-material geometry, encodes the original diffuse maps as quality-90 WebP at their original 4096 x 4096 resolution, and downsamples only roughness maps to 1024 x 1024. Meshopt compresses geometry. Four embedded source texture maps remain embedded and keep their existing material/UV assignments. The GLB uses required `EXT_texture_webp`, supported by the production Three.js GLTFLoader. The supplied PCB outline measures about 53 x 68 mm, close to the Uno R3 mechanical outline (53.4 x 68.6 mm). The whole assembly, including its protruding USB and barrel connectors, measures 53 x 75.45 x 14.28 mm; its logical origin is centered on the PCB, not the connector envelope.

The source is 62,519,672 bytes, 77,734 triangles, 53 meshes, 91 primitives, and 12 materials. The optimized asset is measured in `public/models/arduino-uno-r3.optimization.json`; current conversion yields 4,660,496 bytes, 51,026 mesh-definition triangles, 7 meshes, 10 primitives, and 10 materials. Diffuse maps retain 4096-pixel detail; roughness maps use 1024 pixels. Runtime graphics settings cap decoded texture resolution per device preset, and the model cache shares decoded geometry and textures among component instances. Browser run counts and the 1/10/25 instance benchmark are recorded in `artifacts/arduino-uno-r3-benchmark.json`; visual captures are `artifacts/arduino-uno-r3-visual.png`, `artifacts/arduino-uno-r3-top.png`, and `artifacts/arduino-uno-r3-front.png`, and pin anchors are visible in `artifacts/arduino-uno-r3-pin-anchors.png`.

The benchmark uses Chromium SwiftShader (software rendering), so its frame rate is environment-specific and not representative of a physical GPU. In Balanced graphics at 1600 x 1000, the editor observed 23 draw calls / 102,076 triangles for one instance, 169 / 914,516 for ten, and 198 / 1,119,168 for 25 visible instances. Geometry attribute storage was approximately 0.80 / 0.81 / 0.82 MB, and the model parsed once (about 378 ms) across all instances. Four capped 1024 x 1024 textures have an estimated 21.3 MiB decoded RGBA memory including mipmaps; this is a derived estimate, not a GPU measurement. The short 25-instance camera-motion sample measured 6.78 FPS under SwiftShader. WebP reduces download/storage size, not decoded GPU texture size. The final browser run had no page errors, console warnings, or failed asset requests.

The supplied GLB has no embedded creator, copyright, or license metadata. Its filename suggests a Sketchfab download, but the original page/license cannot be confirmed from the asset alone. Before redistributing this model publicly, verify its source and required attribution/license terms.
